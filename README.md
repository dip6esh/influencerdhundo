# Creator Connect

Let's build the following platform. We won't work with database yet. let's just make the ui/ux end to end.



PRD — influencer Dhundo



Product: influencer Dhundo

Platform: Mobile-first responsive website

Business Model: Creator subscription

Business Access: Free

Core Purpose: Help local businesses discover and contact local creators.





---



1. Product Overview



A directory where local creators can create profiles showcasing who they are, where they are based, what kind of content they create, their audience size, collaboration preferences and starting price.



Businesses can freely browse and discover creators using relevant filters. They only need to create a free account when they want to access a creator's contact number.



The platform acts only as a bridge between businesses and creators.



The platform does not manage or participate in the collaboration itself.

27. Core Product Principle



The platform should answer one question:



> "Which local creators are available for me to discover?"







It does not answer:



> "Which creator should I hire?"







That decision belongs entirely to the business.



The product loop



Creator:

Create profile → Subscribe → Become visible → Get discovered → Receive contact



Business:

Landing page → Find a Creator → Search → Explore → Signup → Get contact → Contact creator



Platform:

Provide the directory → Maintain useful information → Connect both sides → Earn through creator subscriptions.
